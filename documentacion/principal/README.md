## 📊 Información del Proyecto

### 🏗️ **Arquitectura**
- **Frontend:** Next.js 15.5.4 con React 19.1.0
- **Backend:** Node.js + Express + Sequelize
- **Base de Datos:** PostgreSQL
- **Características:** Soft Delete, Control de Stock, Exportaciones

### ✅ **Funcionalidades Principales**
- Dashboard interactivo
- Gestión de usuarios y membresías  
- Control de pagos y caja
- Sistema de ventas y productos
- Control de inventario automático
- Exportaciones a PDF/Excel
- Sistema completo de soft delete

## 🚀 Inicio Rápido

```bash
# 1. Clonar repositorio
git clone [repository-url]

# 2. Instalar dependencias backend
cd backend-gym
npm install

# 3. Instalar dependencias frontend  
cd ../frontend-gym
npm install

# 4. Configurar base de datos
# Ejecutar script DB__Gimnasio.txt en PostgreSQL

# 5. Configurar variables de entorno
# Crear archivo .env en backend-gym

# 6. Iniciar servicios
# Backend: npm start (puerto 3000)
# Frontend: npm run dev (puerto 3001)
```
